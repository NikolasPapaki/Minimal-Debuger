This projects consits of a minimal debugger (mdb), which is able to run and debug
ELF programs in a Linux-based operating system. This mdb is able to set multiple software breakpoints on
code locations of the debugged program and inspect the running code.

This tool alows to add/delete software breakboing either using a symbol or a hex address.
It alsow show the disasembled binary code when encountering a breakpoint
